# Portfolio Completion Checklist

The code repository is cleaned without inventing missing engineering evidence. Before using it as a Structures / AIT portfolio centerpiece, add only real material you can substantiate.

## High-value evidence still not supplied

- [ ] Photo of the actual 1U CubeSat engineering model
- [ ] Photo/diagram showing piezo sensor locations and mounting method
- [ ] Wiring or electrical block diagram
- [ ] CAD screenshot or mechanical assembly view, if you personally have permission to publish it
- [ ] Actual vibration test setup photo
- [ ] Real sample CSV log
- [ ] Plot generated from that real log
- [ ] Test input/reference frequency or excitation method, if one existed
- [ ] Comparison of expected/reference vs measured dominant frequency, if a reference existed
- [ ] Structure material, mass, fasteners, and dimensions only if they are documented and publishable
- [ ] Any calibration method only if it was actually performed

## Do not claim without evidence

- calibrated acceleration in g or m/s²,
- qualification-level launch vibration testing,
- validated structural natural frequencies,
- FFT processing while the repository contains the current direct DFT implementation,
- exact hardware board model unless you confirm it from the physical board/BOM.
