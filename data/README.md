# Data

Measured hardware vibration data is not published in this repository at this time.

The CSV under `tests/fixtures/` is explicitly synthetic and exists only to test the DFT validation and plotting workflow. It should not be interpreted as data collected from the CubeSat engineering model.

If measured data is added later, it should include enough context for interpretation, such as:

- vibration excitation or input method,
- sensor mounting/location,
- acquisition duration,
- reference/input frequency when known,
- whether the recorded values are raw ADC counts or calibrated engineering units.
